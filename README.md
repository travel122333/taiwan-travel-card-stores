# 國旅卡特約商店查詢

方便查詢「國民旅遊卡」特約商店的靜態網頁：可依縣市／鄉鎮／類別篩選，也可用店名關鍵字（容許全半形、公司後綴差異）或電話搜尋，並附國旅卡補助重點提醒。

- 資料來源：NCCC 國民旅遊卡特約商店查詢系統（https://travel.nccc.com.tw/）
- 更新頻率：每週日凌晨由 GitHub Actions 自動重新抓取並部署（網頁會顯示資料更新日與本週新增／解約的店）
- 計程車（約 5.7 萬筆）僅按車隊收合顯示，不逐筆列出

## 本機使用

```
python3 crawl.py 0      # 抓取有效店 → data/stores_active.csv（約 20 多分鐘）
python3 build_data.py   # 產生 docs/data/*.json
cd docs && python3 -m http.server 8765
```

## 聲明

本站為**非官方**網站，與 NCCC、行政院人事行政總處無關。資料可能有延遲或錯誤，是否可請領補助請以官方最新公告及人事單位認定為準；每筆結果均附「到 NCCC 確認」連結。
